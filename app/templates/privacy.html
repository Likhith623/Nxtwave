Privacy Notice & Data Handling

Last Updated: October 2026 • NxtWave Growth Intern Challenge Prototype

1. Zero-Cost & Local Storage Architecture

Project Compass is an educational prototype built with Python, FastAPI, and SQLite. All data submitted through the web interface is stored in a local SQLite database file (local_compass.db). No data is shared with paid third-party vendors, tracking beacons, or data brokers.

2. Information We Collect

  • Project Constraints & Descriptions: Technical inputs, languages, and project ideas used strictly to calculate feasibility scores.
  • Peer Challenges: Edge cases and improvement suggestions submitted under Break My Build.
  • Workshop Registrations: In Mode B (demo mode), student names and emails are stored locally to demonstrate campaign attribution and prevent duplicate submissions.
  • Attribution Events: Standard campaign UTM parameters (utm_source, utm_medium, utm_campaign, ref) to demonstrate funnel analytics.

3. No Cross-Site Cookies or Third-Party Scripts

The application does not use external tracking scripts, Google Analytics, Facebook Pixel, or advertising SDKs. Styles and scripts are self-contained with zero CDN dependencies.

4. Resetting Demonstration Records

Evaluators and administrators can clear and re-seed sample demo data at any time through the authenticated /admin panel or by calling POST /api/admin/reset.

5. Contact & Questions

For questions regarding this prototype or the NxtWave Growth Challenge evaluation, refer to the project README or submission/growth_plan.md.
